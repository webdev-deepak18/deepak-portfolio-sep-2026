# deepak-portfolio-sep-2026

## Deepak S — Senior Brand Designer Portfolio (Tailored for GoComet)

A modern, high-impact interactive portfolio built with React, Vite, and Three.js WebGL, tailored specifically for the **GoComet Senior Brand Designer** interview.

### 🌟 Key Highlights & Architecture
- **Interactive 3D Earth Globe**: Built with Three.js, WebGL shaders, realistic atmospheric Fresnel glow, NASA specular ocean masking, real-world maritime logistics trade routes, and mathematical ray-tangency horizon beacons.
- **Ocean Freight Maritime Layer**: Canvas-driven wave simulation with animated container carriers honoring GoComet's ocean freight visibility network.
- **AI-First Design Showcase**: Demonstrating AI-assisted design systems, workflow automation, high-converting landing pages, and B2B SaaS product collateral.
- **Comprehensive Project Galleries**:
  - **Graphic Design**: Prospectuses, brand collateral, conference brochures, infographics, and construction campaigns.
  - **Websites & AI Workflows**: Event platforms, SaaS dashboards, email builders, and CRM portals.
  - **Motion & Video**: 3D motion graphics, research explainers, and video teasers.
  - **Executive About Section**: 18+ years career progression, AI philosophy, core stack, and credentials.

### 🛠️ Tech Stack
- **Framework**: React 18, Vite
- **3D & Graphics**: Three.js, WebGL, HTML5 Canvas
- **Styling**: Vanilla CSS with GoComet Design Tokens
- **Icons & Assets**: SVG iconography, PDF previews, and optimized image thumbnails

### 🚀 Getting Started
```bash
# Install dependencies
npm install

# Build for production
```
